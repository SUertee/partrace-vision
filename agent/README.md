# Agent 开发入口

主责：韩广宁。对应 D07，D10 后补首页简报。

实现 AI 会话与消息、问题转计划、后端只读检索工具、有效证据引用、run_id 状态、停止与错误回退。聊天和分析历史保存到 `conversations / messages / runs`，与后端共同落实存储；会话按用户隔离，不固定录像；每次运行单独保存一段录像的查询范围，同一会话不同轮次可查询不同录像。保存最终执行的语义检索文本，完成答复只存一份；停止或失败不伪造完成消息，重启后的旧运行明确标为中断失败。

先用共享样例验证，再连接真实后端。Agent 经只读 semantic_search_events 工具检索事件描述向量，再回查事件与真实关键帧；相似度只作候选排序，未索引与无匹配分别说明。Agent 可以写自己的 AI 历史，不自动保存向量或管理员的核查决定。实现语言采用 Python，首版作为独立模块接入后端 FastAPI 应用；数据查询经后端只读工具，模型调用和运行控制保留在本模块。当前目录仅为开发入口，尚无运行服务。

交付与验收见 [开发计划](../docs/DEVELOPMENT_PLAN.md)。

共享接口与数据格式见 [docs/api](../docs/api/README.md)。

对外 AI 接口统一使用 `/api/v1/agent/...`，继续由本模块实现。统一 API 地址及路径是设计约定，当前没有运行服务或已部署的路由入口。
