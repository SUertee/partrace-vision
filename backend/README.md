# 后端开发入口

主责：Harry Xu。对应 D01、D05、D09，另负责 D06 摄像头 SDK 验证。

全部业务模块及表／API 交接见 [模块设计](../docs/modules/README.md)：后端提供 M02–M05、M07 的数据接口，并参与 M06 持久化、M08 汇总、M09 SDK 验证和 M10 P1 包裹。

与 Agent 的下一步交付见 [联动设计](../docs/modules/BACKEND_AGENT.md)：提供鉴权与只读事实服务、AI 历史持久化和原子运行终态；Agent 通过受限 Python 接口调用，首版同应用、单执行实例，不直连 DB。

先冻结共享样例，随后按当前数据库草案实现完整视频结果包导入、事件/关键帧查询、录像范围摘要和单事件核查保存/回读；新增事件描述向量入库与只读语义检索，筛选范围和模型空间一致。与 Agent 模块共同落实 AI 会话、消息和分析运行的持久化，AI 历史接口由 `agent/` 提供。先接模拟输入，再接算法真实事件包；服务重启后必须保留记录。当前目录仅为开发入口，数据库已选 PostgreSQL + pgvector，业务数据与向量同库分表；服务端采用 Python + FastAPI，尚无运行服务。首版在同一 API 应用接入独立的 Agent 模块；视觉处理在独立 Python 工作进程中运行，按结果包交给后端导入。

交付与验收见 [开发计划](../docs/DEVELOPMENT_PLAN.md)。

共享接口与数据格式见 [docs/api](../docs/api/README.md)。

对外数据接口统一使用 `/api/v1`；`GET /api/v1/user` 读取认证主体对应的当前用户资料。App 设计上使用统一 API 地址；路由至各模块的入口尚未实现。

包裹与入出库设计已纳入 `parcels / parcel_records`；作为 P1 拓展在 D10 主闭环验收后实现五个 `/api/v1/parcels` 接口，管理员确认后写入流水，Agent 只读。当前未实现该服务，不将扫码或设计页面当作库存运行凭据。
