## Why

D07（Issue #7）现有 Agent 已提供计划、异步运行、结果卡片和历史接口，但 Android AI 页仍仅保存本地问题。用户已配置 Backend 私有环境，要求同步最新 dev 并接入 Android。

## What Changes

- Android 从统一 API 地址读取已发布且已授权的 SDK／真实预录录像与版本区域，限定单录像范围提问。按用户 2026-10-17 追加要求，mock 不再进入正式聊天可选范围；旧模拟恢复指针退出当前对话，服务端历史保留只读，不重新发起模拟分析。
- 持久保存请求 ID，生成计划后由用户确认运行；轮询现有运行接口，支持停止、恢复、结果卡片与当前证据读取。
- 使用现有分页会话／消息接口回读历史；区分空数据、无覆盖、缺失媒体、权限及依赖失败。
- 提供独立本地 API/Bearer 配置；服务端模型与数据库秘密不进入 APK。

## Impact

影响 `android/`、本地配置准备脚本及 Android 运行说明，消费既有 `/api/v1` 合同。另补最新 dev 已接受的 `runs.cards_json` 的显式增量迁移入口；不改变既有字段合同或增加业务写入接口。D10 同一真实事件闭环仍需另行验收。

## Verification

构建 Debug APK，运行客户端协议／重试恢复测试、lint 与 OpenSpec 检查；可用设备上验证页面、服务访问及现有数据，明确记录外部模型与真实证据链未验证项。
