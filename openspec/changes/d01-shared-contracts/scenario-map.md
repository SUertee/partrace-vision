上述 JSON 是模拟输入／返回形状，不能证明场景已执行。仍需在四方评审与对应工作包核对真实断点、未知 UTC、消息撤权、原子完成、并发重试、停止后的迟到结果及重启恢复；当前 AI 模拟事实引用为空。

`GET /api/v1/overview` 等五个 proposed 与 AI 运行列表候选未加入当前 OpenAPI。首页简报属于 D10 展示，汇总可先组合现有查询，不能把建议入口写成已定义 API。后续契约变化更新本表与活跃规格，不改旧工具接入归档。
