## Why

D07（Issue #7）的 Android AI 追溯入口当前按本地持久会话恢复旧对话。用户在 2026-10-17 明确要求，点击 AI 追溯应默认进入新对话，旧对话通过历史入口手动打开。该要求已确认；本提案记录本次客户端行为调整，不代表实现或真机验证已经完成。

## What Changes

- 仅明确点击首页、事件页或我的页的「AI 追溯」Tab 时请求新对话入口；从证据详情返回、前后台切换、SDK 会话重建和服务设置入口继续保留当前会话。
- 当前没有未完成的真实分析运行时，清除本地当前会话、消息、计划、运行、证据、分页状态和未发送草稿，保留后端配置及已选录像、区域。进入空白页不创建服务端空会话，不删除服务端历史。
- 当前真实运行尚未完成，或启动请求结果不明时，保留稳定 run_id 及确认载荷并恢复该运行，避免新入口遗失停止和恢复依据。该情形是新对话默认规则的安全例外。
- 历史入口仍使用现有 API 分页读取并手动打开旧会话；未完成运行、恢复、重试和独立后端授权继续遵循既有规则。

## Impact

- 工作包：D07，关联真实 Issue #7。
- 依赖：[既有 Android Agent 接入](../d07-android-agent/proposal.md)及其持久运行与历史行为。
- 影响模块：`android/` 的 Tab 导航、AI 页面与 Android Agent 控制器，以及对应模块说明和回归验证。
- 不包含：Backend／Agent 服务端逻辑、API 或 DB 字段变更、会话删除、摄像头控制、模型配置和 D10 端到端验收。
