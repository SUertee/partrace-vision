## Why

首页目前主要展示设备预览，跨摄像头的检测记录需要进入 SDK 单独页面。用户要求新增独立事件页，并确认首先展示摄像头检测事件，沿用现有蓝白渐变、圆角白卡与胶囊导航。关联 D02 / Issue #2，依赖 D06 / Issue #6 的 SDK 会话、事件、图片及回放能力；本 change 不等于 D08 的团队区域事件／证据业务验收。

## What Changes

- 在现有原生工程增加“事件”根级入口，顺序为首页／事件／AI 追溯／我的。事件页沿用当前首页视觉，AI 保留全屏聊天交互。
- 查询当前账号的摄像头检测记录，按手机本地日期、设备及检测类型筛选，卡片展示来源、设备、检测类型、时间、时长与真实缩略图。
- 点击具备录像的事件复用现有回放；缺少录像时提供真实状态，未登录、设备加载／错误、事件失败及未返回事件分别反馈。
- 查询有界、可取消，过滤与排序在适配层明确处理；声明 SDK 结果可能含缓存，达到单次 200 条上限时提示可能不完整，不声称全历史或云端全量。

## Capabilities

### New Capabilities

- `sdk-event-browser`：当前账号摄像头检测记录的独立只读浏览、筛选与回放入口。

### Modified Capabilities

- `station-design`：既有三个主入口扩展为四个，保留消息、SDK 调试及独立 AI 会话。

## Impact

涉及 Android 导航、事件展示与 SDK 只读适配、测试、预览和模块说明；不修改 Backend／Agent／Vision、表、API 或模型。事件页不提供删除／上传／分析操作，不将 SDK 检测记录冒充团队区域动作事实或 Event/Evidence 引用。真实 SDK 查询、缩略图、回放与模拟器 UI／真机分别留证。
