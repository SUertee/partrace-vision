# Design

## Context

用户提供五张设计图：首页、消息中心、AI、通知静音弹层、站点选择浮层。原图基本为 824×1834px，以约 412×917dp 作为布局参考，按可用屏幕空间适配。当前官方 KMP/Compose 工程需继续保留供 SDK 独立实测。

本 change 属于 D02 的视觉实现。已有文档中的首页、事件、AI、记录四 Tab 与本轮三入口设计有差异：此次以用户设计的首页、AI、我的为设计壳入口，独立消息中心不占底部入口；这不删去后续查询、证据、核查与记录业务范围。相关文档同步说明差异，不以本 change 关闭 D02。

已通过本地 GitHub CLI 核对真实 Issue #2；本轮仅覆盖其中的视觉界面，不据此关闭 D02。

## Goals / Non-Goals

**Goals:** 还原五种界面状态；默认进入设计壳；三入口、消息返回、站点选择、定时静音、AI 建议/输入/本地历史可操作；我的说明来源并可进入官方调试界面。

**Non-Goals:** 真实摄像头直播、远端报警、远端 AI 推理、事件查询、证据引用、人工核查、业务历史持久化及 D02/D06/D08/D10 全验收；无 DB/API 修改。

## Decisions

### Compose 设计壳与官方入口分离

在现有工程内新增独立 Compose 页面和本地 UI 状态，由 Android 主入口默认展示。我的提供明确命名的官方 SDK 调试入口，再进入既有 `SampleApp`。保持 Android/Common 的引用关系、包名、SDK 初始化与官方调试实现；不将团队设计样例写进 SDK 设备数据。

### 以截图层级和间距实现可适配布局

首页使用蓝色到浅白渐变、白色圆角卡、深灰视频占位块和底部胶囊导航；消息页使用浅灰底与黄色通知提示；AI 页使用浅青渐变、建议胶囊和渐变描边输入框。图标用 Compose 可缩放绘制，文本与控件适配可用宽度，不将截图作为整页位图。

父层消费真实 status/navigation bar insets，输入区域处理 IME；不复制截图中的时间、电量或导航栏。列表可以滚动，底部导航和输入框不遮住内容。

### 浮层由同一遮罩管理

站点选择锚定标题下方；通知选项使用带左右留白和底部间距的圆角浮动弹层。遮罩、返回键和取消关闭浮层，浮层出现时底层页面不接收触摸。选择站点更新本地标题；静音支持30分钟、1小时、直到重新打开，到期恢复本地通知状态。该静音仅为设计壳状态，不宣称修改系统通知或官方摄像头报警设置。

### 本地交互与真实来源清楚区分

首页两个设备卡及“68”按图展示为设计样例，不表示当前设备数量、温度、电量或实时状态。真实直播、报警与 AI 均未连接；我的集中展示来源与未连接说明，点击尚未接入的操作时给出明确反馈。消息空布局不能被解释成真实零报警。

AI 建议、输入和历史只操作本地内容；可选择建议、提交文本、查看本地历史。未接入的语音、远端查询及推理给出明确提示，不生成看似真实的检索、录像、Event/Evidence 引用或业务成功结果。跨进程恢复及服务端历史不在本次验收范围。

## Risks / Trade-offs

- 截图尺寸不是所有设备的实际 dp；优先保持比例、间距与信息层级，同时处理系统 inset、较小屏幕和键盘。
- 默认入口改变可能使 SDK 验证人员寻找原界面；通过我的中明确的官方 SDK 调试入口保留原路径。
- 本地静音与历史可能被误认成已连接服务；来源说明和操作反馈必须明确，业务连接后再另行定义持久化与同步。

## Verification

按 [Android README](../../../../android/README.md) 在 Android 工程执行 `./gradlew :app:assembleDebug`；涉及资源与平台 API 时执行 `./gradlew :app:lintDebug`。以截图核对五种状态，手动检查导航、浮层遮挡/取消、静音时限、站点更新、AI 本地交互、IME 和 SDK 调试返回；记录设备/模拟器、系统、版本及未验证项。构建、模拟器截图与真机/摄像头验收分别记录。

OpenSpec 使用 1.14.1 执行 `openspec validate d02-station-design --strict --no-interactive`，并执行 `git diff --check`。API 和数据库仅沿用 [现有契约](../../../../docs/api/openapi.json) 与 [SQL](../../../../docs/database/schema.sql)，不为视觉壳新增字段或接口。
