# Design

## Context

`station-design` 已定义默认 Compose 驿站设计壳和保留的官方 `SampleApp` 调试路径，首页设备仍为视觉样例。当前用户授权直接将已登录账号的两个真实设备接入首页；“两个”描述当前账号资源，不构成代码中的固定数量或设备身份。

此 change 关联 D02 / Issue #2 与 D06 / Issue #6。Android 内部接入官方 SDK，不经过 ParTrace Backend，不改变 [模块边界](../../../../docs/modules/README.md)、[数据库](../../../../docs/database/schema.sql)、[API](../../../../docs/api/openapi.json) 和 [共享样例](../../../../docs/api/examples/v0.3)。真实事件、证据和 Agent 仍按后续业务工作包接入。

## Goals / Non-Goals

**Goals:** 在现有首页呈现当前 SDK 账号真实设备；复用初始化、业务登录会话、设备模型、缩略图和官方直播／设置页；正确展示加载、空、未登录、失败与重试；保留设计风格及消息／AI 本地功能。

**Non-Goals:** 两路同时直播、账号或设备数量硬编码、SDK 房屋映射、设备绑定／配网、报警与录像事件、远端 AI、业务 DB／API 改动及 D06 全部验收。

## Decisions

### 复用 SDK 初始化和业务会话

设计壳与官方 `SampleApp` 使用相同的 Koin／SDK 初始化入口，避免创建另一套账号、设备缓存或连接管理器。启动首页时先恢复仍有效的缓存业务会话，再请求 SDK 设备列表；没有有效会话或 SDK 返回 401 时显示明确未登录状态，并允许进入原业务登录界面，完成后刷新首页。不得把“本地配置存在”当作登录成功，也不得输出或提交缓存令牌。

### 首页状态只由真实 SDK 数据驱动

独立共享的设备状态层将 SDK 结果映射为加载、成功、空、未登录或错误。Compose 订阅状态并在显式重试、登录返回或需要恢复刷新时读取设备；请求及缩略图操作不阻塞 UI。状态层不插入样例设备，错误与成功空列表保持不同状态；生命周期结束时停止订阅及正在进行的界面工作。

卡片数量来自列表，名称和在线状态来自对应设备模型。原样例位置、“68”和“安克黑客松”撤下；SDK 未给出名称、在线状态或缩略图时使用明确缺失／未知说明，不能伪造业务值。最近缩略图只说明 SDK 最近图像，不标为实时画面，也不推断连续录像或设备在线。

### 复用真实设备导航并保持返回路径

将首页卡片持有的原 SDK 设备对象／标识交给既有导航：摄像头进入单路直播，基站进入原设置；更多和状态入口进入同一设备设置。原 SDK 页面返回设计壳，不丢失已选底部入口。连接或播放失败由真实 SDK 页面反馈，不生成成功画面；播放器与连接资源沿用原页面的释放方式。

### 多画面先提供真实缩略图网格

保留设计中的多画面入口，打开由当前真实设备构成的最近缩略图网格；明确该网格不是多路实时流。摄像头可点击进入对应单路直播，基站与设置入口沿用设备类型导航。先复用已存在且可验证的单路播放器，避免新增两路同时播放的连接与生命周期约束。

### 本地设计状态不映射为 SDK 业务

站点标题和切换仍仅是界面分组；当前没有经验证的 SDK 房屋映射，因此切换标题不伪造设备归属或筛选结果。铃铛静音、消息空布局、AI 建议／输入／历史维持原本地行为与来源边界。我的来源说明同步为“设备已接 SDK，报警与 AI 服务尚未连接”。原官方调试入口保留。

## Risks / Trade-offs

- 缓存业务会话可能过期；必须使用真实设备列表响应判定可用性，401 回到未登录状态。
- 缩略图可能缺失、过期或读取失败；显示缺失状态，保留设备真实元数据，不使用样例图冒充。
- 当前账号列表可包含基站等非摄像头设备；按真实类型导航，不将所有卡片强行送进直播。
- 模拟器能证明布局与导航，不能独立证明摄像头 P2P／播放能力；本轮服务验证与摄像头验证分开记录。

## Verification

按 [Android README](../../../../android/README.md) 在 Android 工程执行 `./gradlew :app:assembleDebug` 与 `./gradlew :app:lintDebug`；新增共享状态逻辑执行相关既有测试入口。记录本轮 SDK／App 版本、环境、真实设备列表响应、缩略图结果、设备卡与返回导航、加载／空／错误／未登录／重试，以及可用摄像头的实际播放结果。脱敏截图和验证说明不包含 Token、密钥或设备 SN。

OpenSpec 固定使用 1.14.1，运行 `openspec validate d02-station-sdk-devices --strict --no-interactive` 和 `git diff --check`。同步 Android README、相关模块和开发计划后执行文档要求的设计同步检查。只有实际执行后更新任务；未验证的真机／摄像头、D06 事件／回放／下载／定位及 D10 能力继续明确记录为未验证。
