# 真实设备首页接入验证

日期：2026-10-16。范围为当前账号设备接入新首页，关联 D02 / Issue #2 与 D06 / Issue #6，不代表 D06 全部能力或 D10 闭环验收。

## 实现与本地检查

- `StationSdkApp` 共用原 Koin 初始化与 PR/QA 缓存业务会话恢复；未登录分支不渲染恢复出的旧 SDK 页面，认证状态改变时重建设备导航宿主。
- 首页动态投影真实设备，不硬编码两个 SN 或数量。在线属性使用 SDK 属性流订阅，暂无属性时显示未知；最近缩略图不可用时明确显示缺失或失败。
- 复用原 `MegaLiveVideoScreen` / `MegaDeviceSettingsScreen`；原设置页移除设备后的返回改为根栈兼容。验证没有执行删除或修改设备设置。
- JDK 17、Gradle 8.13、AGP 8.11.1、Kotlin 2.2.21、compile/target SDK 36、minSdk 26，未升级依赖或改包名。
- 最终运行 `./gradlew :app:assembleDebug :app:lintDebug :sample-core:testDebugUnitTest --tests 'com.anker.esiotkit.sample.main.mega.SdkDeviceOrderTest'`，构建、lint 和3项测试均通过。测试覆盖缺父设备的摄像头保留、父子排序、空结果，不构建 ViewModel、不请求网络、不调用原生 ThingPayload。
- 最终冷启动核对2张真实卡、2个在线状态且无原样例文案；再次打开第二台直播观察到35 KB/s，返回后 AI 页面与通知弹层仍可进入。
- 加载、空、请求错误、15秒超时、401及恢复栈保护经过源码检查；本次未对获授权账号主动注入401或错误凭据，不声称异常协议已全部实测。

## 真实 SDK 与摄像头操作

运行端为 Android 17 / API 37 的 arm64 模拟器（1080×2400 / 420dpi），使用现有获授权业务会话；没有读取、输出或修改账号 Token。

| 操作 | 本次结果 |
| --- | --- |
| 冷启动进入新首页 | 当前账号返回2台真实设备；名称来自 SDK，其中一台名称为 Doorbell，另一台使用真实设备编号（交接文本不复制完整编号） |
| 在线状态 | 两卡均显示 SDK 的在线状态；首页不再出现“深圳”“68”“安克黑客松”样例 |
| 最近预览 | 两台均显示 SDK 最近缩略图；明确标为最近预览，未把静态图当实时视频 |
| 第一台卡片 → 单路直播 | 成功进入对应设备播放器，观察到实时速率及随时间变化的摄像头叠字；当时画面呈灰色，未判断镜头现场状态 |
| 第二台卡片 → 单路直播 | 成功进入对应播放器，观察到现场视频及网络速率；未操作录制、对讲、警报、灯光或云台 |
| 直播 → 设备设置 → 返回 | 可打开对应原 SDK 设置页，未修改参数；逐级返回新首页 |
| 多画面入口 | 网格显示同账号两台真实设备的最近预览及对应名称；可关闭返回首页 |

带真实画面的截图仅保存于被 Git 忽略的 `android/ESIotKit-DemoApp-Android/app/build/outputs/ui-checks/`，不作为代码或文档提交。APK 位于同工程 `app/build/outputs/apk/debug/app-debug.apk`。

## 边界

站点名称仍是本地界面分组，不映射 SDK 房屋，也不假称设备已被移动到另一站点。多画面是最近缩略图网格并可进入单路直播，不是双路同时播放。AI、报警列表及通知订阅未新增真实接入，本地静音不改变摄像头报警配置。

本次验证使用模拟器连接真实摄像头；未测试 Android 真机、SDK 事件/回放/下载/定位、全部异常协议、Backend/Agent 或 D10 业务。先前设计截图记录保持原样，作为上一轮视觉材料。
