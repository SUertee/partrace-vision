# 设计

Skill 是可信代码内的只读工作指引，不是授权或执行命令。执行提示词只注入名称和用途，模型以 `load_skill(skill_name)` 读取完整步骤；未知名称返回明确错误，不做文件访问。加载指引纳入现有工具预算，不修改确认计划，也不产生事实或证据引用。计划阶段仍只返回 DraftPlan。

Backend Gateway 将语义服务的特定 `503/model_unavailable` 转为无私有信息的 Agent 协议异常，转换前后重新验证范围和权限；其他错误继续传播。Agent 工具将该异常转为 unavailable 数据，标明 `search_events` 可继续使用，且本轮不重复访问故障编码器。该结果没有候选、覆盖计数或相似度，不进入成功语义读取账本。最终答复以确定性文字补充该限制，避免模型省略服务缺口；无须扩充卡片契约。

新增技能代码放在现有 `agent.tools` 包，沿用打包与 Docker 白名单，不增加运行依赖。使用实际 create_agent 图与显式 fake 模型验证选择、加载、调用、参数拒绝、预算和证据引用；Backend 使用独立测试替身验证错误转换与撤权，不调用外部服务。

图步数包含模型、工具及中间件节点，默认从 30 调整为 60，使新增加载步骤能在原有 8 次模型／12 次工具预算内运行；显式较低步数仍单独止损。三种预算失败使用现有 error.code 字符串区分，不扩充字段或路由。部分索引覆盖即使命中候选也生成现有 unindexed 缺口卡。
