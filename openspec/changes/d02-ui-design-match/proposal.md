## Why

用户补充六张 Android 设计稿，要求还原首页、AI 追溯、消息中心的空／通知／列表状态，以及审核记录；随后要求将“我的”页按新增第一张参考图重排，并将 SDK 调试放入右上角齿轮。现有 SDK 与 Agent 已接入，需要保留真实数据与功能入口，同时把已保存审核记录直接呈现在“我的”。关联 D02 / Issue #2，协作 D08 / Issue #8 与 D09 / Issue #9。

## What Changes

- 按原稿还原颜色、边距、字体、圆角、线性图标和渐变输入框；系统栏使用真实系统 inset。
- 首页保留真实设备与预览，人物录像任务入口移入菜单及我的。
- AI 默认画面回归设计，检索范围与服务配置经条件按钮／历史菜单操作，保留计划确认、运行控制、引用和错误。
- 消息与审核使用统一顶栏／通知条，分别实现空态、月份列表和审核卡片；审核只读接入既有接口。
- “我的”采用蓝白渐变品牌头、常驻“检索记录”输入框、“全部”和审核记录卡片，复用既有真实列表、详情与本地搜索；底部保留首页／AI／我的导航。
- 右上齿轮打开设置菜单，收纳 SDK 调试并保留消息中心、人物录像自动解析、审核记录和后端服务配置入口，移除原首屏的大按钮与技术说明。
- 设计样例只用于可明确识别的 Compose Preview，业务页不伪造告警或已保存记录。
- 2026-10-17 用户确认直接改造现有 Android 页面，不拆 `frontend` 模块、不改为 Web。AI 页沿用既有视觉，将欢迎示例及输入提示对齐实际录像查询能力，按后续截图要求移除顶部查询范围卡片，范围仍由底部入口和计划确认查看，默认收起错误码与内部录像编号，证据状态与来源使用可读中文。

- 2026-10-17 按用户要求统一源码与设计资料：页面按 `station/ui` 分组，聊天入口与布局命名对齐，底部导航抽为共享组件；设计图与验证截图统一收进 `android/design`。保持现有界面与业务行为。

## Impact

影响 Android Compose UI、系统栏外观、平台通知权限与只读审核记录适配，不改变 Backend/Agent/DB 合同。“已保存”表示从后端读到持久化记录，不代替详情中的已确认／已排除／待确认结论；本轮不新增保存写入。不包括外部模型诊断或真实摄像头业务验收。
