## Why

用户补充六张 Android 设计稿，要求还原首页、AI 追溯、消息中心的空／通知／列表状态，以及审核记录。现有 SDK 与 Agent 已接入，但新增技术卡片改变了设计层级，审核记录尚无入口。关联 D02 / Issue #2，协作 D08 / Issue #8 与 D09 / Issue #9。

## What Changes

- 按原稿还原颜色、边距、字体、圆角、线性图标和渐变输入框；系统栏使用真实系统 inset。
- 首页保留真实设备与预览，人物录像任务入口移入菜单及我的。
- AI 默认画面回归设计，检索范围与服务配置经条件按钮／历史菜单操作，保留计划确认、运行控制、引用和错误。
- 消息与审核使用统一顶栏／通知条，分别实现空态、月份列表和审核卡片；审核只读接入既有接口。
- 设计样例只用于可明确识别的 Compose Preview，业务页不伪造告警或已保存记录。

## Impact

影响 Android Compose UI、平台通知权限与只读审核记录适配，不改变 Backend/Agent/DB 合同。不包括外部模型诊断或真实摄像头业务验收。
