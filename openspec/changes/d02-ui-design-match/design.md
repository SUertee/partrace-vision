## Context

此前六张参考图保存在 `android/design/references/`，尺寸 824×1834，以 412×917dp 为设计基准；新增第一张“我的”参考图要求蓝白品牌头、搜索、已保存记录与右上齿轮。实际页面沿用 Kotlin/Compose，外层已处理系统栏，保留 SDK 与后端两套独立授权。

## Decisions

- 原稿视觉参数直接落实为 Compose 组件；图标使用 Canvas 路径，不引入图片生成或额外依赖。
- 首页移除占据首屏的任务卡片，功能保留在设备菜单／我的；设备和在线状态仍来自真实 SDK，不用设计中的“68”等值代替。
- AI 问题前的服务和录像信息移入对话框，四个条件按钮提供可达入口；运行中继续显示实际状态和可取消操作。
- 消息、审核复用顶栏与通知权限提示；通知状态随回到前台刷新。无告警接口时显示真实空态；审核使用原 `/api/v1/review-records` 只读读取及本地搜索。
- “我的”改为记录列表主页面：渐变从顶部延伸至搜索附近，品牌标记及“驿站追迹”在左，齿轮在右；搜索框常驻，支持已有事件编号、审核编号、备注和本机时间的本地匹配，清空后恢复全部记录。
- “我的”与独立审核页共用列表／详情读取和状态组件，继续消费 `GET /api/v1/review-records` 与 `GET /api/v1/review-records/{id}`，不新增接口或复制请求协议。卡片显示真实事件编号、由 UTC 转本机时区的时间和“已保存”；点击卡片展示既有详情及真实核查结论。
- 齿轮打开可关闭的设置面板，提供 SDK 调试、消息中心、人物录像自动解析、审核记录与服务设置；入口间往返保留来源与底部导航。SDK 调试仍调用既有原工程回调，People 任务配置与服务凭据继续由现有独立页面管理。
- 未配置、正在加载、读取失败、没有记录和没有匹配各自反馈；设置与服务配置入口在这些状态下仍可达。搜索聚焦时遵循现有键盘 inset，列表内容保留底部导航的空间；设置面板拦截底层触摸并支持返回关闭。
- 纯预览明确采用设计样例，可独立验证有记录画面，不修改生产数据。

## Verification

执行 Android Debug 构建、lint 及已有 Agent 协议回归；在模拟器检查导航与布局，并以 Compose Preview 或实际页面记录对应截图。新增“我的”验证覆盖真实审核只读、搜索／清空、详情、齿轮各入口与返回、键盘及安全区；预览分别展示有记录和异常状态，验证凭据在实际执行后补充。图像数据和模型效果不作为本轮 UI 验收。
