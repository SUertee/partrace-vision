## Why

用户提供 P1 Agent 对话与工具过程、P2 事件过程、P3 摄像头所有事件三张图，要求相关片段和事件列表共用可追溯详情。关联 D08 / Issue #8、D02 / Issue #2，依赖 D07 / Issue #7 的只读 Agent 与 D06 / Issue #6 的 SDK 来源映射。当前聊天只显示通用卡片与关键帧弹窗，SDK 列表直接回放，工具实际进度未向客户端提供。

## What Changes

- 将对话展示调整为用户蓝色气泡、助手正文、真实工具进度与淡紫色相关片段入口，保留真实录像选择、计划确认、停止、历史与错误。
- 新增共用事件过程详情，聊天与 SDK 列表均可进入，提供真实事件时间线、关键帧及原 SDK 回放入口；返回保留来源页面。
- 按设备 SN 与原生事件 ID 的稳定 People job 对应到录像，逐项核对 SDK 事件、镜头、配置和服务来源，不能按相似时间或名称拼接。
- GET Agent run 添加可选、有界、进程内真实工具进度，不保存模型思考／参数／全文结果。历史或重启缺记录时明确无进度，不从计划推导完成。
- 2026-10-17 用户追加：相关片段详情通过现有受权原片接口回看真实录像，从当前事件偏移开始播放，并保留完整上下文；原片仅在用户点击后读取至私有临时缓存。
- 同日真机点击回归：Android 聊天的后台事件详情由不对外导出的独立 Activity 承载，复用原事件页面及仓库；与主页面的 SDK 导航栈隔离，返回结束该 Activity 并恢复原会话。只传事件／录像／可选证据 ID，仍重新检查后台身份和归属；其他平台及 SDK 列表保留原导航方式。

## Capabilities

### New Capabilities

- `agent-event-detail`: 共用事件详情、真实来源关联、过程与关键帧浏览。
- `agent-tool-progress`: 当前进程内真实只读工具执行状态及兼容展示。

## Impact

Android 对话、事件页、只读详情仓库及现有 Agent GET run 响应增加可选字段；不新增 HTTP 路由、不改 SQL／SSE 语义。不自动上传、解析、下载原片或开始新模型运行。不存在真实遮挡区间或跨镜关联时不复制设计示例。SDK、API、预览与真机实测分别记录，D10 不因 UI 接通而完成。
