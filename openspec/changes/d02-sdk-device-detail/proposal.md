## Why
用户要求按新设备详情稿重排首页点击进入的 SDK 页面，并完整保留原 SDK 功能。关联 D02 / Issue #2 与 D06 / Issue #6。

## What Changes
- 将原直播页组织为标题、画面、五项快捷控制及事件／录像卡片。
- 保留 SDK 播放器、设备能力判断及所有控制回调，额外能力经更多控制展开。
- 为当前设备提供事件、事件录像回放、全部录像及下载队列入口，设置仍打开原 SDK 页面。
- 设计中的商业云存储区域用于实际 SDK 录像管理，不添加不存在的购买功能。

## Impact
仅 Android SDK 页面与导航；无 Backend/Agent/DB 契约变更。模拟器界面验证不代表真机或全部摄像头能力验收。
